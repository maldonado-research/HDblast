# Error evidence in the separate outer envelope

The numerical shape in `OUTPUT_SCHEMA.json` contains the complete outward
moment intervals. `total_absolute_radii` must equal the exact sum of real and
imaginary half-widths from those endpoints. These complete radii determine the
registered whole-interval `1e-26` gate. Metadata naming a source tail or a ball
midpoint cannot replace those endpoint-derived values.

The outer driver must authenticate a separate error-evidence artifact for each
route. This artifact records the fixed exact source-model tails, local
pointwise phase/kernel tails, integrated-kernel factor of two, physical panel
scale factors, absolute coefficient-weighted propagation, optional global
small-phase kernel tails and the actual interval implementation/runtime pins.
The final checkpoint includes `Lg`; its source-model bound is distinct from the
bound for `g`. Its source primitive is not the action-derived finite-band work.

If a zero-model-tail re-evaluation is reported to inspect coefficient/arithmetic
ball width, label it as the enclosure width of the polynomial computation with
those specified model tails suppressed. It is not automatically an additive
partition of the full enclosure's width, nor a bound on all full-run rounding
after adding model tails. The complete numerical run must still include every
registered model and arithmetic contribution. Do not obtain an error component
by subtracting favorable signed residuals or by assuming that two empirical
evaluations enclose the exact target.

The outward remainder/radius rounding in the independent route must retain the
proved `q <= ceil(q*2^512)/2^512 < q+2^-512` guarantee. Record its use at every
registered cumulative radius update; omitting that accumulated radius from
serialization is an execution defect. A fabricated serialization failure from
denominator growth must be preserved with its zero-real-source chronology.

Uniform analytic model proofs and numerical probe widths have separate scopes.
The proof covers both sources, all 64panels and real `k` in `[0,256]`; the complete
computed numerical widths are established only at the registered nine rational
momenta. Outer bootstrap, exact remote public-byte verification, whole-route
wall/RSS receipts and independent proof review are prerequisites for a result
named `PASS_UNIFORM_MODEL_AND_REGISTERED_PROBE_CERTIFICATE`. The standalone
output validator deliberately does not issue that global proof status.
