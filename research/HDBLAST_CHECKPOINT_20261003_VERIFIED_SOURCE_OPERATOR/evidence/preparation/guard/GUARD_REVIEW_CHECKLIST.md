# Narrow operator registration review checklist

Status: **SOURCE_ONLY_REVIEW_IN_PROGRESS; NO_EXECUTION_AUTHORIZATION**.

The target is both real analytic sources, all 64 exact panels, all nine exact
rational momentum probes, 1152 panel moment rows and 18 whole-interval moment
rows, plus 128 panel and two whole-interval Lg rows, registered with includeLg
true. A source/operator prerequisite is not a twelve-case
action-pressure/contact/continuity certificate. No actual source callback or
inherited array decode is allowed in this review.

## Before numerical-core import

- A stdlib-only bootstrap validates the exact finalized registration schema,
  canonical integer chronology zeros, source names, all rational geometry and
  probe membership, final include-Lg decision, configuration and fixed budget.
- Public verification refers to a full immutable 40-digit Git commit. The
  downloaded registration and every registered source/proof/schema blob have
  exact SHA256 and byte-length checks against the complete inventory. A status
  string or plausible hash shape alone is not independent readback evidence.
- The actual local bootstrap is in that verified source inventory and checks
  its own bytes. The pre-import guard checks every core/wrapper/validator byte
  before importing it, including all permitted helper imports.
- Registration, inventory, public-readback receipt, environment arithmetic
  pins and filesystem paths are validated before an actual callback can run.
  Avoid circular claims where a self-generated receipt alone supplies all pins.
- Unknown, duplicate, omitted or renamed keys are rejected. Exact integer
  counts reject booleans and strings. NaN/Infinity and duplicate JSON keys are
  fatal. Guards use explicit branches, not removable assertions.
- Actual-route entry rejects stale or occupied output paths, forbidden array
  inputs, unsupported configuration, root execution and incompatible backend.
- Full actual-wrapper fabricated replay uses the same finalized schema and
  guards, with a clearly separate manufactured source-provider hook; it never
  substitutes an unguarded real source for the manufactured provider.

## Enclosing numerical target

- Primary: correct normalized source derivatives, explicit/restored Arb series
  cap, source degree24 Cauchy tail, entire phase degree96 and every phase/kernel
  tail, rational input conversion, source/Lg coefficients and global transport.
- Independent: own exact source coefficients and exponential bracket, explicit
  dyadic point errors, actual residual of delivered degree96 polynomial,
  correct source sign, exact rational phase and inherited endpoint-radius carry.
- Verify k=0 and tiny positive k without a singular quotient. Do not apply a
  degree96 global phase series to a phase as large as512.
- Distinguish the uniform analytic source tail, coefficient approximation,
  phase/kernel or polynomial-defect error, and total returned interval radius.
  Component budgets are proved upper bounds, not inferred signed residuals.
- Lg is a scalar analytic source primitive, not the missing full finite-band
  action baseline work or contact integral.
- Whole-interval sums enclose the original continuous target with all local
  errors and global transport. An endpoint difference is not a substitute.
- Source is real. M0 and Lg have exactly zero imaginary target. Mexp and Mu are
  real at k=0. The primary generic core uses conservative rectangular complex
  tail inflation, so narrowing its zero-k output requires an explicit proof of
  this registered target's reality; generic arbitrary incoming-state responses
  cannot be projected in the same way.

## Output and comparison

- Emit reduced exact rational outward endpoints and verify positive denominator
  and ordering. Every export encloses its delivered internal result or has an
  explicitly justified target-specific projection.
- Calculate complex absolute radius from the actual exported endpoints as
  real half-width plus imaginary half-width. A maximum component radius is a
  different quantity. Reported radius must equal this declared calculation.
- Check exact ordered row inventory, no duplicates or omission, exact panel
  cover, exact source/probe names and every required channel, for each final
  configuration. M0/Lg momentum-independent consistency remains explicit.
- Compare both complete independent certificates by component intersections,
  preserving original intervals and signed differences. An intersection is a
  valid common enclosure only after each route's bounds and authentication pass.
  Overlap by itself is not proof of either route's enclosure validity.
- Do not choose a narrower row, degree, mesh, configuration or subset based on
  the real outcome. Uniform model claims and observed probe-radius claims are
  separate.

## Outcomes, resources and preservation

- Successful narrow status requires all uniform proofs, routes, output guards,
  controls and registered resource receipts. It does not authorize a stronger
  physical claim.
- A finite valid enclosure wider than1e-26 is an unresolved probe radius, not
  scientific PASS. A disjoint independent enclosure/failed identity is a
  certificate consistency failure.
- Nonfinite or negative/invalid bounds, bad schema/pins, inward serialization,
  unsupported arithmetic, timeout/RSS overrun and missing outputs are execution
  failures. Preserve partial outputs, logs, actual source-evaluation chronology
  and unchanged thresholds.
- Each accepted real-source attempt is written and fsync'ed to a fresh external
  metadata-only journal before the source callback can start. Failed execution
  receipts retain its byte count and SHA256, including zero-attempt runs.
- Use the finalized nonroot one-thread/no-child contract. The authoritative
  wait4 wall/RSS receipts include source coefficient production, every row,
  whole-interval outputs, serialization and final validation.
- Resource limits require two complete fabricated whole-route receipts per
  route and the predeclared headroom rule. A smaller generic benchmark or an
  internal self-reported RSS is not the authoritative resource evidence.
- Check all frozen bytes before, between and after route execution. Never
  overwrite a failed attempt or call a marker repair a blind confirmation.
