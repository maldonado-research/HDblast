# Execution and chronology contract

The checkpoint is a prospective source/operator prerequisite, separately from
the twelve-case pressure/contact conservation study. No inherited array is an
execution input. Definitions of the exact analytic source may be read before
registration; its actual Taylor coefficients may only be evaluated after the
complete public registration has been independently downloaded and checked.

The custodian commits the full source, mathematical proofs, configuration,
schema, preparation tests and independent GO review. `FULL_REGISTRATION.json`
binds SHA256 and byte length of every member, with no circular self inventory.
The public freeze commit binds this registration too. A separate API readback
downloads every registered Git blob, checks its Git blob hash, SHA256, byte
length and path, and records the public repository and exact freeze commit.

The numerical child receives explicit SHA256 pins for the registration and
that readback receipt. It checks every member and its readback binding before
importing any numerical source. It rejects duplicate JSON keys, nonfinite JSON
constants, Boolean chronology counts, missing or modified source, symlinks,
unregistered Python sources, cached bytecode and local extension modules. The
complete numerical/execution/schema core must be covered by the independent
pre-freeze review. The immutable configuration retains its pre-execution
status; result and readback evidence are separate additions.

The source authorization callable permits exactly one construction for each
of two sources at each of64registered exact centers. The independent route
uses its own source algebra. Source callbacks and archived-array decodes are
counted separately; the latter remain zero. The fabricated entry substitutes
explicit artificial source models, never the registered source callback, and
records its zero real-source count. It cannot be presented as a real result.

The custodian launches the scientific child as the existing nonroot user with
an explicit minimal environment and one numeric thread,120seconds wall/CPU
and128MiB address-space/RSS limits. The child forbids subprocess creation.
The outer `wait4` report, exit status and timeout determine execution success;
an internally reported time is not authoritative. Source bytes are rechecked
after computation. Scientific inconclusive or failed width gates are valid
recorded outcomes; malformed/missing output or resource failures are execution
failures and cannot be converted into certificates.

The offline guard authenticates consistency with the archived readback and
its caller-supplied pins. It does not supply a cryptographic signature proving
that an arbitrary receipt came from GitHub. The original custodian's API
readback and its disclosed chronology are explicit provenance premises.
Likewise, this is validated numerical computation under the stated analytic
and library contracts, not proof-assistant formalization or external review.
