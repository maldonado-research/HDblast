## 1. Conventions and the change of first-jet variables

Let `E` be exactly the direct-sum bundle used in INITIAL_TRANSPORT:

```
E = R_v + Sym^2(R dt + T*S3)_H + R_w + (R dt + T*S3)_D.
```

It has rank sixteen and its positive fiber norm uses the full Frobenius
norm on the symmetric block. Its connection is the split-preserving
product connection, trivial in `t,z`. In the stereographic round
orthonormal component frame write

```
D_i = partial_i + Omega_i,
H_ij V = D_i D_j V - gamma^k_ij D_k V,
```

where in the second line `D_i D_j` differentiates the bundle component
with direction label `j` kept fixed, and `gamma` is the product base
connection of `dt^2+dz^2+kappa`. Equivalently `H=D^2` is the usual
bundle covariant Hessian, including its derivative index connection.
The notation below avoids counting that base connection twice.

The pinned coordinate equation is

```
q^{ij}(x,V) partial_i partial_j V = f(x,V,P),
P_i = partial_i V,
f = c(x,V) + b^i(x,V) P_i + d^{ij}(x,V)(P_i,P_j),
```

with `d` symmetric in its two combined direction/fiber slots. Throughout,
`q` means the physical inverse metric, not a positive reference metric.
The exact expression for `f` in COEFFICIENTS contains the actual reference
Christoffel symbols `K=Gamma[g0]` and `partial K`; these are never frozen
or removed in this calculation.

Set `Q_i=D_i V`. Then `P_i=Q_i-Omega_i V`. Expanding the Hessian and
substituting this identity gives the exact equation

```
q^{ij} H_ij V = Fbar(x,V,Q),

Fbar(V,Q) = f(V,Q-Omega V)
  + q^{ij}[Omega_i Q_j + Omega_j Q_i - gamma^k_ij Q_k
            +(partial_i Omega_j - Omega_j Omega_i)V].       (A)
```

The term involving `gamma Omega V` cancels. This cancellation is an
identity, not a smallness estimate. In particular simply adding equation
(3) of COEFFICIENTS and then relabeling its old `P` as `DV` would omit
terms such as `-b Omega V`. Equation (3) is correct in its stated old
coordinate first jet; equation (A) supplies the additional substitution.

The coefficient extraction in the new first jet is therefore

```
cbar(V) = c(V) - b^i(V) Omega_i V
  + d^{ij}(V)(Omega_i V,Omega_j V)
  + q^{ij}(V)(partial_i Omega_j-Omega_j Omega_i)V,

bbar(V)Q = b(V)Q - 2 d(V)(Omega V,Q)
  + q^{ij}(V)[Omega_i Q_j+Omega_j Q_i-gamma^k_ij Q_k],

dbar(V) = d(V).                                             (B)
```

The signs of the connection matrices are fixed by `D=partial+Omega`.
Changing component convention changes all occurrences together. Symmetry
of `q` makes its contractions with `Omega_j Omega_i` and
`Omega_i Omega_j` equal, without any assertion that those matrices
commute individually.

## 2. Exact zero-state linearization and ordered energy maps

All maps in this section are evaluated at `V=0`. Put

```
A = c_V(x,0),          B^k = b^k(x,0),

        + q0^{ij}(partial_i Omega_j-Omega_j Omega_i),
Bbar^k = B^k + 2 q0^{ik} Omega_i - q0^{ij} gamma^k_ij I.
                                                               (C)
```

Since `c(x,0)=0`, the background field is identically zero in these
variables. Consequently differentiating the principal coefficient does
not add a first-wave term: `q_V[V1] H(0)=0`. The exact first-wave
equation is

```
q0^{ij} H_ij u = Abar u + Bbar^k D_k u.                       (D)
```

Choose the global invariant round frame `E_A` with
`[E_A,E_B]=2 epsilon_ABC E_C`, and put

```

s(t)=sech(t),   h(t)=tanh(t),
W_i=D_(X_i)u.
```

These are the directions in the retained energy estimate. There are two
distinct connections to keep track of: the fixed product base connection
used to define `H`, and the varying physical reference connection already
contained in `A,B`. The former satisfies

```
nabla_t X_A = -h X_A,       nabla_(X_A) partial_t = 0,
nabla_(X_A) X_B = s epsilon_ABC X_C.
```

Because the bundle product connection has no mixed time/angular
curvature,

```
D_t D_(X_A)u = D_(X_A) D_t u - h D_(X_A)u,
H(t,X_A)u = D_t D_(X_A)u + h D_(X_A)u
           = D_(X_A)D_t u = H(X_A,t)u.                       (E)
```

Thus the derivative of the moving frame and the base-Hessian correction
cancel in the full mixed product Hessian. The spatial correction in the
contraction is
`sum_AB q^{AB} s epsilon_ABC D_(X_C)u=0` by symmetry of `q`.
The cancellation does not discard any physical/reference connection
term. The energy differentiation itself still has the moving-frame
term retained in ENERGY_MAJORANT (5).

For general `q`, these identities identify the negative product-Hessian
contraction with the ordered scalar principal operator of the energy
proof. At the background, explicitly,

```

c_principal^{ij} = rho^-2 delta^{ij},
P0 u = a u_tt - c_principal^{ij}D_(X_i)D_(X_j)u

```

Let `M_mu^i` be the pointwise scalar matrix expressing the coordinate
direction `partial_mu` in `(partial_t,X_z,X_1,X_2,X_3)`; its temporal
entry is one. Equation (D) is precisely

```

L_t=Bbar^t,
L_w(W)=sum_(mu,i spatial) Bbar^mu M_mu^i W_i,
```

Orthogonal changes between stereographic and global invariant round

Use the retained homogeneous outer Dirichlet wall at `z=Z`, which is

## 3. Numerical operator norms of all lower maps

Write `C=10^150000`, the pinned ceiling on the sum of absolute coefficient
entries for each fixed ordinary mixed base/state partial through sixteen.
The distinction between one such partial and a sum over state directions
is relevant: `A=c_V` has sixteen state columns. Thus

```
entrysum(A) <= 16 C,      entrysum(B) <= C.
```

On the independent symmetric coordinates the Euclidean norm and the full
Frobenius direct-sum norm satisfy
`|v|_2 <= |v|_E <= sqrt(2)|v|_2`. A coordinate matrix with entry sum
`S` therefore has `E -> E` operator norm at most `2S`; the same bound
applies to a first-jet map from the full direct sum of direction copies.
It follows that `||A||<=32 C` and `||B||<=2 C` in coordinate directions.

For precision about the elementary connection bounds, write
`sigma=2/(1+|xi|^2)`, `ell_i=partial_i log(sigma)`. On `|xi|<=1`,

```
|ell|_2 = 2|xi|/(1+|xi|^2) <= 1,
||partial ell||op <= 2,
omega_i = e_i ell^T - ell e_i^T.
```

The angular one-form connection matrix has norm at most one. Its
derivative has norm at most two. Induction to the rank-two symmetric
block, with the Frobenius norm, gives for every angular coordinate index

```
||Omega_i||op <= 2,       ||partial_j Omega_i||op <= 4.
```

The other connection matrices vanish. Also for each coordinate pair,
`sum_k |gamma^k_ij| <= |ell_i|+|ell_j|+|ell|_1 <4`.
The inner physical inverse-metric certificate gives
`sum_ij |q0^{ij}|<1`. Therefore the connection addition to `B` has
operator norm at most `2*2+4=8` in coordinate first-jet directions,
and the final connection term in `Abar` has norm at most `4+2*2=8`.
The term `B^k Omega_k` is bounded by `4 C`: apply the entry-sum bound
to the separate maps and the uniform bound two on each `Omega_k`.

In angular directions the coordinate-to-moving conversion is
`D_(partial_xi)=sigma cosh(t) D_(X_round)`, followed by an orthogonal
rotation; `sigma cosh(t)<4` on the retained interval. Consequently

```

l_w = ||L_w:E^4 -> E|| <= 4(2 C+8)=8 C+32 <9 C,
l_0 = ||L_0|| <= 32 C+4 C+8 <40 C.                           (G)
```

For the first line the connection correction in direction `t` is exactly
zero: `Omega_t=0`, `gamma^t=0`, and `q0^{it}=0` for `i!=t`.
These inequalities bound the complete lower maps in (F), including all
original bulk reference terms through the certified `c,b` envelope.
