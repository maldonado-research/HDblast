## Minimal premises and exact boundaries

The five natural-source joins use the static shell background, nonzero
`rho,c`, `R0=P0=0`, zero first mixed shell traces and their tangential
derivatives, and the first physical metric rows with tangential derivatives
only. The intermediate identity retains `R1=0` and leaves the scalar
amplitude `p1` free. It is not the fully off-shell identity for arbitrary
nonzero `R1`. The final natural divergence equality additionally uses
`P1=p1Y=0`. The first harmonic normal row, bulk equations, background bulk
ODEs and the hyperbolic identity are unnecessary for this particular join.
This absence of premises is not applied indiscriminately to the other
calculations in the capsule.

The normal-gauge companion first distinguishes actual and background
lowering with `Hy` free, then explicitly imposes the retained normal harmonic
row to match the shell adapter. The numeric-wrapper check verifies its
symbolic input interface and conventions; it does not independently evolve
the underlying interval first-wave construction. The first-wave operator
binding has its own derivative/background identities and retains the actual
wave's PDE, zero initial data and regularity as analytic premises.

The induced Robin result uses the reduced second equation, the natural
normal-tangential equation and the normal subsidiary condition. A zero
normal trace alone would not impose a Robin law on an arbitrary tangential
covector. The corrected README now states these hypotheses explicitly.

The README also now distinguishes `p1=sy-ph/2+sigma2v/2` from the full scalar
residual `P1=p1Y`. The displayed first-wave normalization includes `Y` in
both scalar covector components and uses `bar_D Y` for the unit-sphere
gradient. These resolve the notation ambiguities identified in this review.
