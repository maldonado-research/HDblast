# Historical input

`CHARGED.json` is an exact copy of the machine result in the immediately preceding charged-heating release. The finite-time and spinor calculations use its density-bearing neutral precursor as a prescribed geometry and field history. The late-expansion calculation also uses the earlier clock-activated solution for comparison. The present coupled solver computes its own initial-to-final history.
