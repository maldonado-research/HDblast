# Prospective records and execution order

The primary four-point quantum-source matrix has not been executed at this
commit. Its registration, executable and validator bytes were frozen locally
before source values, then committed here before the primary matrix starts.
`PREREGISTRATION.json` pins each hash and the inherited scientific inputs.
The grid, precision sequence, analytic tail bounds and acceptance gates are
fixed in `REGISTRATION.md`.

The independent proper-time calculation and classical sensitivity calculation
have separate local prospective registrations written before their numerical
runs. Those runs began before this public commit. Their included registrations
are accurate local execution records; this commit is not an external advance
registration of those already-started checks. Their results and execution
receipts will be added separately after review.

This is a mathematical quantum-source benchmark and a differential response
of an existing classical branch. It does not select physical HDBLAST masses
or gravitational matching, or execute a coupled cosmological evolution.
