## Requirements for reproduction

To reproduce an original code result, obtain the actual versioned package, dependencies, parameter card, input bytes, and original runbook. Do not infer an environment or successful run from this documentation.

For the intended strict A2 analysis, additionally require compatible PTA posteriors and priors, independent sampling units, a documented overlap/disjointness treatment, justified frequency-grid compatibility, physically harmonized ringdown parameters with applied transformations, source permissions, a non-circular evidence/replay inventory, and estimator accuracy control.

The private v6.3 proof definitions, exact fixed-domain moment formula, Brier certificate, DKW-Makarov propagation, and code must be recovered before their reported guarantees can be independently reproduced. No research script, expensive computation, or new observational test was executed for this edition.

## Preservation limits

Essential figures include SR-envelope plots, Beta-family phase maps, A1 contours, and calibration diagnostics. Markdown does not preserve their plotted geometry; this publication includes no reconstructed replacement figure.

Posterior arrays, HDF5/tar data, executable source trees, JSON receipt schemas, and original release archives are absent. The three failed task attachments (`TOE-Mds-Transfers.zip`, `Antimatter-MDs-Transfer-Files.zip`, `HDBLAST-Mds-Transfer-Files.zip`) concern other programs and are neither required nor used as FTL evidence.

Raw private transcripts, the unpublished book manuscript, credentials, personal contact details, unrelated research archives, and the earlier mixed-program article ZIP are excluded.
