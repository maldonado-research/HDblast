# Independent direct forced-mode stress: prospective registration

This implementation and registration precede all new physical source sampling,
response, stress, or mode calculations in this round. Syntax-only compilation
and exact integer source-derivative algebra are permitted before the root's
verified public freeze. Every numerical execution must supply its public
freeze commit and the independently pinned manifest SHA-256. No parameter,
local contact, source, state or tolerance changes may follow inspection of
outcomes without a separate registration.

## Frozen physical problem and output units

Use the exact inputs in `../EXPERIMENT.json`: H=1, r=2, xi=0, a=-1/eta,
fixed geometry and unchanged incoming BD state, eta_i=-6, eta_f=-1.5,
epsilon=1e-4. The explicitly reused sources are s=epsilon B(u) and
s=epsilon u B(u), u=eta+4, B=exp(1-1/(1-u^2)) for |u|<1 and zero otherwise.
Their IDs are `positive_B` and `signed_uB`. Observations are -5.5,-4.5,-4,
-3.5,-2.5,-1.5; the comoving cutoffs are 64,128,256. This is a linear
prescribed-source experiment, not a finite-amplitude nonlinear mode solve.

The flat summary `rows` array has one record per source and observation.
Each `finite_k` entry has a `values` mapping:

| Key | Definition |
| --- | --- |
| q | a^2 deltaQ_K/epsilon |
| q_prime | (a^2 deltaQ_K)'/epsilon |
| q_second | (a^2 deltaQ_K)''/epsilon |
| rho | a^4 delta_rho_K/epsilon |
| p | a^4 delta_p_K/epsilon |
| Q0 | Physical finite-K matched Q0,K, without epsilon division |
| anomaly | a^4 deltaA_K/epsilon |
| current | a^2 delta_j_K/epsilon, b=1 |

The source record `source_jet_over_epsilon` contains f0,...,f5, the first
six conformal-time derivatives of s/epsilon. For b=1, the independently
declared mass-law translation is `current=q+Q0*f0/4`; this is not a stress
definition.

## Independent forced canonical modes

Evolve delta v=v u, u'=w, w'=2ik w-s, with u=w=0 initially and
v=exp(-ik eta)/sqrt(2k). This is the actual forced canonical mode equation
delta v''+k^2 delta v=-s v with zero perturbation of the initial state.
Use the exact local homogeneous propagator on each time step and an
eight-point Gauss-Legendre source integral restricted to that step. No primary
global sine/cosine memory routine or producer module is imported.

Use `expm1(2ik h)` and its analytic quotient by 2ik, with the removable zero-k
limit, for the local propagator and forcing. The same expm1 value may supply
both propagator coefficients. Evolve the genuine independent complex u and w;
never impose or project a Wronskian constraint. Monitor the maximum of
|2Re(u)-Im(w)/k|/epsilon over every node at every step. Independently reconstruct
v,delta v,v',delta v' and their physical linear Wronskian at every step.

All forcing, evolution, stress, derivative, subtraction and momentum-summation
arithmetic uses NumPy longdouble/clongdouble. Require a longdouble fraction
mantissa of at least 63 bits and record its actual dtype, mantissa and epsilon.
The fixed GL8 and GL16 nodes/weights are generated by NumPy's double-precision
leggauss and cast to longdouble before use. Their finite precision belongs to
numerical quadrature error, not an interval enclosure. There is no physical
timing or accuracy pilot before publication.

The exact integer recurrence P0=1,

    P_(n+1)=(1-u^2)^2 P_n' + [4n u(1-u^2)-2u]P_n,
    B^(n)=B P_n/(1-u^2)^(2n),

generates the first six source derivatives. For the signed source use
(uB)^(n)=u B^(n)+n B^(n-1). Evaluate the support endpoints and exterior as
exact zero. No finite-difference source derivatives are used.

## Direct physical stress and complete subtraction

At every step construct the actual complex variations

    delta v=v u, delta v'=v(w-ik u),
    Dv=v'-L v, delta Dv=delta v'-L delta v, L=-1/eta.

Compute each physical minimal-stress variation directly from
2Re(conj(Dv)delta Dv), 2Re(conj(v)delta v), and its explicit operator mass
contact +s/(2k) for density or -s/(2k) for pressure. Pressure is never defined
from density, a Ward equation, a trace equation, or a variance closure.

Construct the fixed-reference omega=sqrt(k^2+2a^2), omega',omega'', reference
U=W2, deltaW2 and its two derivatives, deltaW4, and deltaJ4. Differentiate the
complete inherited rho2+rho4 and p2+p4 expressions. The density implementation
retains the algebraically cancelling terms 2U deltaW2/omega-sU/omega^2.
Pressure retains its full deltaW4 and hence source second derivatives.
Combine bare and subtraction terms pointwise before any momentum sum.

Variance jets use the actual amplitudes,

    A=Re(u)/k, A'=Re(w)/k, A''=Re(2ik w-s)/k,

and the complete derivatives of C=-s/(4omega^3). In particular A'' is not
replaced by an expression that assumes Im(w)=2kRe(u). The baseline Q0,K is
integrated directly from [1/(2k)-1/(2omega)+U/(2omega^2)]/a^2.

As a separate diagnostic, integrate the direct subtraction trace mismatch.
With each stress subtraction multiplied by a^4 and Bsub=1/(2omega)-U/(2omega^2),
the per-mode a^4 anomaly variation is

    delta e_sub-3delta p_sub-2a^2 C-s Bsub
      +(C''-2L C'-2L^2 C)/2.

This anomaly calculation defines neither physical stress. Its exact finite-K
comparison and the actual derivative/stress UV-tail bounds are supplied by
the independently registered primary and theory routes.

## Resolution, independent Ward ledger, budgets and gates

Use two settings, each with eight local time nodes and sixteen momentum nodes
per panel:

| Setting | dt | k panel width | Steps | Momentum nodes | Direct-stress history points |
| --- | ---: | ---: | ---: | ---: | ---: |
| coarse | 1/128 | 1/2 | 576 | 8192 | 577 |
| fine | 1/256 | 1/4 | 1152 | 16384 | 1153 |

Local time/momentum pairs per source are 37,748,736 and 150,994,944. There are
4,608 and 9,216 local source nodes, plus the 577 and 1,153 uniform history
nodes where the complete source jet and direct stress are evaluated. Run each
source once at each setting. Every observation is an even Simpson endpoint.

Store direct R=a^4 delta_rho/epsilon and P=a^4 delta_p/epsilon, Q0,K and the
source jet at every time step for all three cutoffs. Form the separate Ward
ledger integrand

    F=a^4 Q0,K delta x'/(2epsilon)+L R-3L P,
    delta x'=(s'-2Ls)/a^2.

Integrate F by uniform composite Simpson quadrature from the initial zero
density to every observation, then compare the integral with direct R.
Neither the stress integrands nor R are reconstructed from this ledger.
Report coarse and fine ledger values, each endpoint discrepancy, and the
coarse/fine ledger difference separately.

Use exactly the root experiment's gates: q and q_prime refinement <=2e-10;
q_second, rho and p refinement <=1e-8; normalized Wronskian <=1e-10;
fine Ward endpoint discrepancy <=2e-6; Ward ledger refinement <=1e-6.
Additional Q0, anomaly and current refinement differences are reported, with
no independent-only acceptance gates. For each quantity report twice the
refinement difference as an empirical estimate, not a certified bound.
The independent validator applies the root's cross-route and finite-K trace
gates and compares continuum results with separately justified tail bounds.

Require exact zero perturbation quantities throughout the source-free initial
interval; baseline Q0,K itself need not vanish. No interval proof of the finite
time, finite momentum, or Simpson integrations is claimed. The variance tail
bound alone is not a bound on stress or derivative response.

Stop at 900 seconds or a Linux ru_maxrss of 262144 KiB. Preserve failure
evidence; never respond to a failed gate by adjusting parameters or contacts.

## Archives, provenance and failure preservation

`MANIFEST.json` pins this document, the producer, the root experiment and the
two inherited subtraction/protocol documents. The CLI requires
`--freeze-commit` (the actual 40-hex Git commit), `--manifest-sha256` and a new
`--output-dir` outside the frozen checkpoint. Resolve the output path and reject
any path within that checkpoint before creating files. Verify manifest
and source pins before numerical physical evaluation. Python 3.12 and NumPy
2.2.6 are required; record the actual Python patch release. No existing output
directory is overwritten.

Each source/setting archive contains longdouble k and momentum_weights;
clongdouble u_i,w_i; source_jet_i=f0,...,f5; and
`integrand_<quantity>_i` for the eight output quantities at all six observations.
The latter already include k^2/(2pi^2), the stated normalization, and pointwise
subtraction. `bare_rho_i`, `sub_rho_i`, `bare_p_i`, `sub_p_i` contain the
a^4/epsilon per-mode terms before the measure. `delta_W2_i` and `delta_W4_i`
preserve the actual subtraction variations.

Histories contain eta, the (time,cutoff,quantity) values array, the independent
Ward integrand, the source jet and physical delta x'. Names and cutoffs are
saved in the same archive. Archive hashes identify actual saved files;
longdouble padding is not assumed to give byte-identical archives on replay.

Record active source, setting, step, eta and Wronskian, retain completed
observations, and preserve current u,w, completed snapshots and available
history in an uncompressed failure snapshot if evolution raises an exception.
Write completed runs incrementally and all exception metadata to results.json.
All checks use explicit exceptions and remain active under Python optimization.

This calibrates linear stress/current on one prescribed geometry and state.
It does not establish a full metric response, shell evolution, quantum
stability, particle yield, radiation transfer, heating or thermalization.
