# Reproduction commands

All commands use one core per process: `export OMP_NUM_THREADS=1`. Time series (*.npz) and checkpoints (*.pkl) are git-ignored and must be regenerated. B2's shell_cache (~1.1 GB) can also be regenerated. `queue.sh` skips jobs whose summary JSON already exists. Audit scripts are in each workstream's `audit/` folder and are described in its AUDIT.md.

## B1_derived_chi_source (~75 min of 5D runs on 1 core)
```
cd B1_derived_chi_source; export OMP_NUM_THREADS=1
python3 b1_symbolic.py            # B1_SYMBOLIC_CHECKS.json
python3 b1_reduced.py             # B1_REDUCED.json
./queue.sh jobs_cal.txt; ./queue.sh jobs_grid.txt; ./queue.sh jobs_explore.txt
python3 -W ignore b1_analyze.py > b1_analyze.out   # B1_RESULTS.json
python3 -W ignore compare_reduced_5d.py           # B1_REDUCED_VS_5D.json
python3 -W ignore explore_analyze.py              # B1_EXPLORE.json
./chain_after.sh                                  # blow-up diagnostics in diag/
```
