## The highest-priority application is already exact

The proposal's source-free oscillatory ledger has an explicit antiderivative of the same kind used in Levin integration. With its existing definitions `Omega=2k`, `E'=i*Omega*E`, `L'=L^2`, `w_a=i*Omega*d`, define

```
p(t) = d*(3*L(t)^2-i*Omega*L(t))/(2*k*epsilon).
p'(t)+i*Omega*p(t)
  = ((2*k^2*L(t)+3*L(t)^3)*d+L(t)^2*w_a)/(k*epsilon).
```

The nonoscillatory primitive is `3*Re(c)*L(t)^2/(2*k*epsilon)`. Therefore integrating the directly expanded free `F_k` reduces to the endpoints of this primitive plus `Re(p*E)`. This mapping is an algebraic consequence of the proposal's free ODE and stress expressions. It neither uses measured final density to define the integral nor assumes that a numerical trajectory follows that ODE accurately. Preserve `Re(c)` and the actual unprojected initial modes.

This makes the registered exact free-phase test the first priority. An approximate Levin or Filon solver would add an unnecessary algorithm choice to these twelve tests. Those methods instead provide a later route for active-source histories, where envelope dynamics and subtraction contacts must be specified independently. No new algorithm or cutoff should be selected after observing the diagnostic.
