# Remaining calculations

The current result is a necessary second-order rotational restriction.
The next question is whether rotation-admissible first-order packets admit
second-order corrections satisfying the full bulk and interface equations.
That requires solving the inhomogeneous constraints and evolution problem,
checking all interface traces, and accounting for second-order shell motion.
The commuting quadrupole criterion classifies all ten Lorentz tests in the
fixed radial-profile, time-scale, and reflection-parity family, with the four
boost tests zero by parity. It does not settle the full nonlinear constraint
range.

One focused next calculation is the full second-order initial constraint
problem for a commuting state with
`A=B=diag(1,-1,0,0)` and both displacement and velocity present. Derive the
coupled initial-data chart, gauge and interface conditions; compute every
quadratic source sector; characterize the adjoint domain and source range;
and solve for unrestricted second-order corrections, including shell traces.
The scalar master sector need not close at second order. Formal second-order
solvability would still leave higher-order obstructions and nonlinear
existence open.

Further work must identify additional possible adjoint constraints and
classify the tests in the general state space, specify the function spaces
and gauge treatment for nonlinear evolution,
and determine whether the total physical pairing admits a useful energy or
stability interpretation. The present restriction supplies no positivity or
cosmological inference. The earlier finite-slab linear shell-contact theorem
remains the frozen prior input; it is not a nonlinear existence theorem.
