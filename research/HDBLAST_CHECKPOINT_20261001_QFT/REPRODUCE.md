# Reproduce the quantum-source checkpoint

Download [HDBLAST_CHECKPOINT_20261001_QFT.zip](HDBLAST_CHECKPOINT_20261001_QFT.zip) from this directory, or check out the complete GitHub branch. Unzip and enter HDBLAST_CHECKPOINT_20261001_QFT/. This package contains the exact selected scientific inputs; no private chats or Drive access are needed.

Python 3.12, NumPy 2.2.6, SciPy 1.15.3 and Matplotlib 3.10.1 were used for the first executed run. The independent implementation uses Node.js 22; its first evaluation also ran directly in V8.

```sh
python -m pip install numpy==2.2.6 scipy==1.15.3 matplotlib==3.10.1
python code/verify_inputs.py
python code/quantum_source.py --registration REGISTRATION.md --registration-sha256 481cbe98c642fc4821ec1f244c3b8db680f5935604800b8a75df07bcdad623c6 --source-ref local-replay
python code/publish_diagnostics.py
mkdir -p outputs/replay
node code/coherence_controls.js > outputs/replay/coherence_controls.json
node code/independent_modes.js > outputs/replay/independent_rk4.json
node code/endpoint_basis_check.js > outputs/replay/endpoint_basis_check.json
python code/verify_independent.py
node code/matching_diagnostic.js > outputs/replay/matching_diagnostic.json
```

The ten-case Python experiment takes a few minutes on the tested runner. All cases, including failed cases if present, are retained. Compilation and input verification precede integration in CI.

Fresh Python outputs go in outputs/actual_modes/, including complex modes and diagnostic arrays in NPZ format. The curated first-run report is outputs/actual_modes.json; it is intentionally separate and retains its original source commit and hash. outputs/primary_curves.json and the two SVG figures are exported from that first run. The independent first-execution outputs are also retained separately. Fresh replay outputs do not overwrite this evidence.

The large per-case mode NPZ files are regenerated by the code and uploaded as GitHub Actions artifacts. Those artifacts have finite retention; the permanent package contains raw background data, exact source, full result JSON, selected curves, figures and independent checks needed to reproduce them.

From the extracted directory, check the downloaded ZIP at its actual path:

```sh
python code/verify_package.py ../HDBLAST_CHECKPOINT_20261001_QFT.zip
```

The verifier checks ZIP CRCs, safe unique paths, exact inventory and every SHA-256 digest. MANIFEST.sha256.json hashes all packaged files other than itself; the ZIP does not recursively contain itself. Its overall SHA-256 and byte count are recorded in the publication PR.

Raw classical summaries preserve the original non-finite markers (NaN); Python's JSON reader accepts these historical records. These markers are not introduced into the new mode result. NumPy inputs are loaded with allow_pickle=False. The selected histories later stop non-finite; the declared endpoint is earlier, as specified in REGISTRATION.md.

Numerical tolerances test this finite-band experiment. They do not certify a continuum geometry, Hadamard state, absolute renormalized source or coupled five-dimensional evolution.
