# A checkable contract for a physical model comparison

8 October 2026. No higher-dimensional physical model is selected by this contract. The present experiment remains a prescribed scalar response on fixed four-dimensional de Sitter space. Completing its numerical certificate and specifying a physical origin model are separate tasks.

The machine-readable companion `MODEL_TEST_CONTRACT.json` contains seventeen required fields. Each future model entry needs a declared value, a versioned derivation or evidence artifact, and a review outcome. A justified not-applicable entry must be checked against the actual observable map. Unspecified fields do not acquire values from literature examples.

An encompassing four-dimensional effective-input class can reproduce any included bulk-induced forcing under the common initial-state, background, contact and measurement assumptions. Restricted rivals can still be compared or falsified. A successful joint test supports its specified model relative to those rivals; it does not automatically detect spatial dimensionality. Priors, locality, positivity, stability and ultraviolet assumptions can restrict the allowed classes, and those restrictions must be explicit.

A useful test must add an action-derived restriction to the present effective source. For example, one may derive response and fluctuation kernels from one bath/action, or a relation between independently measured channels. Matching only a mean response does not match an open-system probability law. Additional channels should be evaluated with the same parameters, preparation and background, including correlations and approximation errors.

The cited Rao et al. teleparallel KK construction is a test-design example only. Its six-to-one dispersion-shift relation is conditional on its action and declared regime; its three-to-one photon-rotation/GW-eikonal-phase relation additionally requires shared emission and detection endpoints. Neither relation is a prediction of the current HDBLAST scalar model. The source distinguishes GW eikonal phase from CBC Fourier phase and retains radion friction; a quantitative observational test must do so too.

No model fit, physical source evaluation, saved-array read/decode, trajectory calculation or observational likelihood evaluation is performed by this contract. The unchanged full pressure/contact integral and UV completion remain unresolved. Higher-dimensional cause is NOT_ESTABLISHED and external mathematical novelty is NOT_ASSESSED.
