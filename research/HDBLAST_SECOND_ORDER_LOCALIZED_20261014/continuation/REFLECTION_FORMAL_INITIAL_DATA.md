# Reflection symmetry removes local KID obstructions at every finite order

14 October 2026 (America/Los_Angeles). Prepared for Ricardo Maldonado with substantial OpenAI Codex assistance and independent internal agent review.

Conditional on the corrected localized linear solvability theorem of the
14 October checkpoint, there is a useful formal consequence. This is
initial-data mathematics; no convergent series, exact nonlinear family,
evolution through shell contact, or novelty certification is asserted.

## Proposition

Let the fixed radial time-symmetric Einstein–scalar background satisfy the
checkpoint hypotheses (`Ω>0`, `Φ′≠0`, smooth background and potential).
Let `𝒜={r₁<|x|<r₂}` avoid the shell and vertex. Fix an orthonormal
coordinate basis and let `Γ≅(Z₂)^4` be the group generated by the four
coordinate reflections. Let `v` be a smooth `Γ`-invariant first-order
ADM datum of compact support in `𝒜`, with `P v=0`.

For every finite `N≥2`, there exist smooth `Γ`-invariant data
`u₂,…,u_N`, compactly supported in `𝒜`, such that

```
x_N(ε) = x₀ + εv + Σ_{j=2}^N ε^j u_j/j!
C(x_N(ε)) = O(ε^{N+1}).
```

The statement holds in every fixed spatial `C^k` norm for which the
constraint map and the necessary derivatives are defined. More precisely,
all derivatives in `ε` through order `N` vanish at zero; Taylor estimates
then hold after using the corresponding finite number of spatial and
potential derivatives. The coefficients may be chosen inductively as one
consistent formal sequence. The construction can be performed separately
on both interior copies.

## Proof

The constraint map is natural under spatial diffeomorphisms, including
reflections, using the usual absolute-density transformation rule for
densitized momenta. Since the background is invariant, its linearization
`P` is `Γ`-equivariant. If `u₁=v,u₂,…,u_{n−1}` have already been
constructed, the `n`th constraint coefficient has the form

```
P u_n + F_n(u₁,…,u_{n−1}) = 0.
```

The differential expression `F_n` is smooth, compactly supported in the
finite union of the previous supports, and is `Γ`-invariant. Its
Hamiltonian component is a scalar; its momentum component is a covector
density.

For completeness, with `u₁=v` and the factorial convention above,
`F_n` is the **nth derivative**, not the coefficient of `ε^n`:

```
F_n = Σ_{k=2}^n Σ_{j₁+⋯+j_k=n, j_i≥1}
      [n!/(k! j₁!⋯j_k!)]
      D^k C|_{x₀}[u_{j₁},…,u_{j_k}].
```

The inner sum is over ordered tuples. Since `k≥2`, each index is at most
`n−1`. Thus `F₂=D²C[v,v]`,
`F₃=3D²C[v,u₂]+D³C[v,v,v]`, and
`F₄=4D²C[v,u₃]+3D²C[u₂,u₂]+6D³C[v,v,u₂]+D⁴C[v,v,v,v]`.
The source to be solved is `S_n=−F_n`. These are formal Taylor derivatives
of a smooth nonlinear differential operator; analyticity is unnecessary.
For the Einstein–scalar constraints the lower coefficients of the metric,
scalar, contravariant momentum density and scalar momentum density are all
included in `u_j`; no scalar or momentum sector is omitted.

On a concentric annulus the full adjoint kernel is the four boost lapses
`Ωx_a` and the six rotations `Y_ab=x_a∂_b−x_b∂_a`.
Reflection of coordinate `a` sends `Ωx_a` to its negative and sends
each `Y_ab` involving `a` to its negative. Since the source and the
integration domain are invariant, change of variables gives

```
∫ Ωx_a (F_n)_H dμ_{γ₀} = 0,
∫ Y_ab · (F_n)_M d⁴x = 0.
```

This is equivalently the fact that the local KID space has no nonzero
`Γ`-invariant vector. All necessary per-copy orthogonality conditions
are therefore automatic.

More explicitly, write `R_σ=diag(σ₁,…,σ₄)`, `σ_i∈{−1,+1}`.
Pullback acts on the KIDs by the characters

```
R_σ* (Ωx_a) = σ_a Ωx_a,
R_σ* Y_ab   = σ_aσ_b Y_ab.
```

Every one of these characters has zero average over all sixteen sign
choices. The source law is
`(F_n)_H(R_σx)=(F_n)_H(x)` and
`(F_n)_{M,i}(R_σx)=σ_i(F_n)_{M,i}(x)` for covector components. The
absolute density factor is one because `|det R_σ|=1`.
Moreover `Y_ab^i(R_σx)=σ_iσ_aσ_bY_ab^i(x)`, so the momentum pairing
integrand transforms by `σ_aσ_b`, exactly as needed. Integration uses
the positive volume/density measure; orientation reversal introduces no
additional sign.

Predetermine increasing smooth concentric annuli with
`supp v ⊂ 𝒜₁`, `closure(𝒜_j) ⊂ 𝒜_{j+1}` and all closures
inside one fixed `𝒜_∞ ⋐ 𝒜`. At stage `n`, the previous
coefficients have support inside `𝒜_{n−1}`, so the source is
compactly supported in `𝒜_n`. Apply the corrected localized
solvability theorem **on `𝒜_n` itself** to get a smooth correction
`z_n` of compact support in `𝒜_n` with `P z_n=−F_n`. The average

```
u_n = |Γ|⁻¹ Σ_{g∈Γ} g* z_n
```

is invariant, smooth, compactly supported in `𝒜_n`, and solves the
same equation because `P` commutes with the group action. This completes
the induction. Every coefficient vanishes on common fixed neighbourhoods
of the shell and vertex because every `𝒜_n` lies in `𝒜_∞`.

For a fixed finite `N`, the metric in `x_N(ε)` is positive definite
for sufficiently small `|ε|`, and the Taylor expansion is well defined.
These facts do not imply convergence as `N→∞`.

## Copy parity and the shell collar

For identical first-order packets on the two copies, choose identical
formal coefficient sequences. For opposite first-order packets under the
fixed copy identification, start from one formal sequence and set
`u_j^−=(−1)^j u_j^+`. Each term in `F_n` then acquires the sign
`(−1)^{j₁+⋯+j_k}=(−1)^n`, so the second sequence solves every
coefficient equation too. An opposite-copy first-order packet therefore
has even-order corrections of the same sign on both copies. The nonlinear
truncated path need not have fixed odd copy parity at nonzero `ε`;
rather copy exchange is accompanied by `ε↦−ε`.

Choose concentric annuli inside one positive-`s` collar that stays a fixed
distance from both shell and vertex. The common fixed neighbourhoods
outside `𝒜_∞` contain neither sources nor corrections at any finite
order. Every shell initial-data Taylor jet there can equal the background.
This is a support and initial compatibility statement, not a solution of
the shell equations after the packet has propagated to the shell.

## Application to commuting quadrupoles

Real commuting symmetric matrices `A,B` admit simultaneous orthogonal
diagonalization. In that basis the master data

```
q=G(s) xᵀ A x,     p=K(s) xᵀ B x
```

are invariant under all independent coordinate sign changes, and the ADM
reconstruction is equivariant. Thus any smooth compact-support commuting
quadrupole packet in the checkpoint class meets the proposition's
hypotheses. In this invariant sector, the finite-order local constraint
obstructions vanish at every order, rather than only at second order.

This uses standard equivariance, finite-group averaging, and the known
localized linear solver. It does not show that arbitrary charge-free
packets outside this symmetry sector have higher-order solvability.
Nor does it replace the outstanding second-order shell-contact evolution
problem. An exact nonlinear initial-data theorem would additionally require
a nonlinear inverse-function or gluing argument with controlled function
spaces and estimates.

## Exact finite-group checks

`check_reflection_formal.py` verifies all sixteen characters, the absence
of invariant KIDs, covariance of all four reconstructed first-order ADM
sectors for an independent diagonal matrix pair, the covector-density
pairing, and the factorial convention for orders two through six. A
negative control restricts the group to identity and central inversion:
all six rotations then remain invariant. A noncommuting quadrupole pair
is invariant under central inversion and has nonzero rotational pairing.
Thus antipodal evenness alone is insufficient for the all-order argument.
The checks substantiate the finite algebra; the smooth operator and
induction arguments above remain mathematical proofs rather than outputs
of a PDE solver.
