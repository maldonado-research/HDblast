# An exact angular verification of the Hamiltonian correction

This calculation strengthens verification of the existing localized
second-order initial data. It adds no claim about nonlinear existence,
shell-contact evolution, or a cosmological inference. The argument was
independently checked by an internal AI referee; it is not external peer
review.

Let `γ₀ = Ω(s)²δ` in four spatial dimensions, `s = |x|²`. For a symmetric
metric perturbation `h` with `tr_δ h = 0` and `h_ij x_j = 0`, the radial
background Ricci tensor and `dφ₀ ⊗ dφ₀` are linear combinations of `δ` and
`x ⊗ x`, so their contractions with `h` vanish. The linearized Hamiltonian
constraint is therefore half the double covariant divergence of `h`.

Directly from the conformal Christoffel symbols,
`∇_j h^{ij} = Ω⁻⁴ ∂_j h_ij`. The connection terms and derivatives of `Ω`
contract `h` with `x` or its trace. Since `√γ₀ = Ω⁴`, its second divergence
is `Ω⁻⁴ ∂_i∂_j h_ij`. Thus

```
P_H[h,0] = (1/(2Ω⁴)) ∂_i∂_j h_ij.
```

Write `P = sδ − x⊗x` and
`h_T = s P Hess(χ) P − tr(P Hess(χ) P) P/3`. In the orthonormal sphere
frame this tensor is `r⁴ (Hess_{S³} χ)^{TF}`. For `Ric_{S³} = 2g`,

```
div_{S³} div_{S³} (Hess_{S³} χ)^{TF}
    = (2/3) Δ_{S³}(Δ_{S³}+3)χ,
P_H[h_T,0] = s/(3Ω⁴) Δ_{S³}(Δ_{S³}+3)χ.
```

These identities also hold when each angular coefficient is a radial
function. For `h = f(s)H` with `Hx = 0` and `tr H = 0`, the extra terms in
`∂_i∂_j(fH_ij)` are `2 f_i ∂_j H_ij + f_ij H_ij`. Differentiating `x_i H_ij = 0`
gives `x_i ∂_j H_ij = −tr H = 0`; `f_i` is radial and `f_ij` is a combination
of `δ_ij` and `x_i x_j`. Both extra terms vanish. Projecting the Hessian of
a radial coefficient times an angular polynomial yields only further radial,
mixed, or tangential pure-trace terms, all removed by the tangential
trace-free construction.

For `χ = C₁(s)(x₁²+x₂²) + C₂(s)(x₁²−x₂²)²`, the script
`new/angular_exact.py` verifies the two angular normalizations directly by
Cartesian symbolic differentiation. It substitutes the published radial
coefficient formulas and verifies

```
P_H[h_T,0] − S_H + f₀ = 0
```

as an exact polynomial identity after imposing
`x₄² = s − x₁² − x₂² − x₃²`. All remaining background and profile jets stay
as free symbols. Reducing spatial polynomials on each sphere before the
radial coefficient substitution avoids the much larger coordinate expansion
that previously stalled. A sign-flipped `C₁` coefficient produces a nonzero
residual and is detected.

The source `S_H` is regenerated by the original Einstein–scalar jet engine.
