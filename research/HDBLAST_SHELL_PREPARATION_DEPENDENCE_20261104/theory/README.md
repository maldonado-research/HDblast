# Elementary preparation certificate

Run from any directory with Python's standard library:

```
python -I -S -B produce.py --repo-root REPOSITORY --output /ABSOLUTE/FRESH_OUTPUT.json
python -I -S -B -O produce.py --repo-root REPOSITORY --output /ABSOLUTE/FRESH_OPTIMIZED.json
```

Both results must equal `references/NORMAL.json` byte for byte. The producer
authenticates its two retained source files before reading their scientific
values and uses exact rational arithmetic. `PROOF.md` establishes its
continuous analytic bump bounds and sign gates. `PROTOCOL.json` binds the
unchanged scientific method and reference.

Run the replay and source-tamper controls with

```
python -I -S -B checks/run_controls.py --repo-root REPOSITORY --output /ABSOLUTE/FRESH_CONTROLS.json
```

This is an alternative coarse sufficient bound for the same fixed direction
as the main cell calculation. It adds no PDE observation or new oracle call.
The output must be an absent file at a normalized absolute path with an
existing parent. Rejection uses exit status 2, one exact JSON stdout line,
empty stderr, and creates no output. All negative control subprocesses use
`-I -S -B`, with `-O` in the optimized case; each report records their exact
exit status, stdout, stderr, flags, and output absence.
