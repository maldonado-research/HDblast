# Project provenance

Before this edition, the Zenodo creator-name query returned **68 distinct version records in nine concept series**. The ORCID query returned 58 of the 68. Ten older versions lack that ORCID in the creator entry. The default latest-version query returned ten rows, two sharing the main HDblast concept ID. The series count therefore uses unique concept IDs from the complete result. The catalog records every title, record ID and concept ID, all three query URLs and page lengths. The GitHub account exposed eight public repositories. [Metadata snapshot](CATALOG.json) · [Zenodo author results](https://zenodo.org/search?q=metadata.creators.person_or_org.name%3A%22Maldonado%2C%20Ricardo%22) · [GitHub projects](https://github.com/maldonado-research?tab=repositories)

Two records had appeared since the previous catalog. The scalar work and decay study supplies the distinction between source work and radiation energy. The incoming pulse study supplies the matched shell histories and their quiet control. Among the eight default-branch heads, only HDblast changed over this interval. The review found no new input to this experiment from the seven other repositories. A local search of the D-Blast 3 study material located the 6 September 2026 note *An exactly calculable quantum production channel*. Its Eq. (6) gives the occupation for a prescribed hyperbolic-secant pulse, including exactly reflectionless pulses. Eq. (13) gives the source-work balance for a time-dependent mass. The note explicitly leaves the brane-derived trajectory and backreaction open. Those earlier calculations establish priority within the project for the prescribed-pulse example. The catalog includes the archive filename and SHA-256 digest, and the analytic quench paper is publicly accessible.
