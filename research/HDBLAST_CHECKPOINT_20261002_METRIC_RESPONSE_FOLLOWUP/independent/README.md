# Independent metric response producer

This route evolves the actual forced incoming-BD canonical modes for
`a=a0(1+epsilon h)`, `a0=-1/eta`, fixed physical `x=r=2`, and minimal coupling.
It evaluates both minimal stresses directly. The Ward ledger is a separate
diagnostic and never defines a stress.

`forced_metric.py` transports `u=delta_v/v`, `w=u'` with the exact free
propagator and local GL8 forcing quadrature. The force is
`epsilon*(4L^2 h-2L h'-h'')`. No Wronskian projection is applied.

`metric_wkb.py` is generated by the exact symbolic `specialize_wkb.py`.
It evaluates the complete directional frequency/W2/W4/J2/J4 inventory from
analytic frequency and metric jets. The generated 161 common subexpressions
avoid propagating unnecessary Taylor coefficients in the physical producer.
`SPECIALIZATION_PROOF.json` records exact derivative checks; the independently
authored generic Taylor/dual evaluator is retained in the separate theory
package and is used to audit this specialization and the raw output.

The only prefreeze execution allowed here is pure symbolic algebra or runtime,
integer recurrence, and array-size preflight. This command performs zero
physical evaluations:

```bash
source /workspace/hdblast-cloud-setup/activate-frw.sh
python forced_metric.py --preflight
```

All registration bytes, files, semantic settings/gates, and the independently
pinned local manifest must verify before a physical source call. Python3.12,
NumPy2.2.6, unoptimized execution, and longdouble mantissa at least63 bits are
required. The output directory must be new and external to the checkpoint.

`results.json` contains four runs (`positive_B`/`signed_uB`, coarse/fine),
their six observation rows, and combined refinement rows. Each finite-K row
contains `q,q_prime,q_second,rho,p,Q0,rho0,p0,current`. The normalizations are
`q=a0^2 deltaQ/epsilon`, `rho=a0^4 delta_rho/epsilon`,
`p=a0^4 delta_p/epsilon`; the primes differentiate scaled q. All three baseline
quantities are actual physical finite-K values without epsilon division.
For fixed phi, b=1 and x_phi=2, `current=a0^2 delta_j/epsilon=q`.

All three baselines are separately integrated from exact rationalized
bare-minus-complete-subtraction integrands in `stable_baselines.py`. Their
symbolic proof is in `BASELINE_RATIONALIZATION_PROOF.json`. Horner polynomials
in `k/omega` and the exact identity `omega-k=2a0^2/(omega+k)` avoid subtracting
the ultraviolet leading terms. Raw literal bare/sub pieces and literal
differences are retained alongside the combined differences. The physical
response scale contacts use these same exactly equivalent baseline
differences. This algebra was fixed before any new physical evaluation.
Outside the exact compact support, directional local contacts vanish and the
producer uses exact homogeneous transport. It skips those identically zero
local-contact operations at non-observation history steps; all baselines
remain evaluated and every observation retains the complete inventory.

Four `metric_modes_SOURCE_SETTING.npz` files retain extended real/complex
arrays. Observation arrays have suffix `_0` through `_5`. Canonical complex
`delta_v,delta_v_prime,delta_D_v` contain the actual epsilon-scaled variations;
`u,w` use the same convention. Canonical `bare_delta_*`, `sub_delta*`,
`delta_omega_n`, and `delta_C_n` are directional coefficients divided by
epsilon. Baseline `sub_R0/R2/R4`, `sub_P0/P2/P4`, `sub_S0/S2`, their directional
counterparts, W2/W4/J2/J4, and all variance derivatives are retained.
Separate mode/operator/mass/scale contact arrays permit direct reconstruction.
The canonical energy variation array is a diagnostic and carries no claim
about particles, yield, or heating.

Every timestep retains actual cutoff observables, six source jets, four
forcing jets, background metric/mass jets, and the ledger integrand
`L*rho-3L*p-3h'*a0^4*(rho0+p0)`. The histories define neither stress.
Momentum modes and per-mode contacts are retained at the six observations;
the complete histories are scalar cutoff sums, keeping the frozen memory
budget256MiB. The frozen wall budget is900seconds. Refinement differences are
numerical estimates rather than certified integration-error bounds.
