# Exact localized initial data and short precontact evolution

14 October 2026 · GitHub research continuation · conditional analytic result

For the reflection-invariant quadrupole sector, the corrected annular
constraint solver and explicit weighted nonlinear estimates give a family
of **exact nonlinear initial data** tangent to the chosen linear datum,
at any fixed sufficiently high finite Sobolev regularity. Under the stated
regular-background Cauchy assumptions, this family has an exact evolution
for a common sufficiently short interval before shell contact. An open
shell collar remains equal to the background, so all junction conditions
hold exactly there.

The concrete commuting choice `A = B = diag(1,−1,0,0)` belongs to this
class for the smooth annular profiles of the preceding checkpoint. The
proof uses a weighted Banach implicit-function theorem, followed by local
Einstein–scalar evolution and finite propagation for the actual perturbed
metrics. It does not rely on convergence of the earlier formal series.

This is an existence construction in a specified finite regularity class,
with an operator formula for its second initial derivative. It is not a
closed-form evolved metric or a numerically evolved shell-contact solution.
Evolution through contact, the complete quadratic bulk tensor source and
the coupled boundary well-posedness argument remain open. Spatial smoothness
to every order on one parameter interval, global stability, external novelty,
and a higher-dimensional origin of the Big Bang are not established.

The proof received independent internal AI-assisted review; this is not
external peer review. The earlier frozen localized and material capsules
retain their original scope and hashes. No new Zenodo version or APS
submission accompanies this continuation.
