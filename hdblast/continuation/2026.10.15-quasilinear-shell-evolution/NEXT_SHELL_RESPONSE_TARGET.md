# Next target: a gauge-invariant response on the physical shell

Planning note following the conditional exact finite-regularity evolution
checkpoint. This note does not claim that a nonzero shell response has
already been calculated.

The exact aligned family now supplies a controlled setting for an observable
calculation, subject to its background, fixed-data, region and finite-time
hypotheses. The next task is to use its actual first and second initial jets,
rather than identify its second correction with a different earlier Taylor
construction.

1. Define the pullback of the scalar to the physical shell, including any
   shell-embedding variation before fixing coordinates. The background
   shell value is constant. Its first variation is therefore a useful
   gauge-invariant response candidate; in the fixed-shell gauge it is the
   scalar first variation evaluated at the shell.
2. Specify a physical slicing or clock before interpreting an exact
   finite-amplitude time series. One possible choice uses proper time from
   the specified initial shell section, on an interval where that intrinsic
   construction is regular. Prove the needed regularity instead of treating
   coordinate time as automatically observable.
3. Compute the complete linear response from the registered annular
   quadrupole data, using the full metric/scalar boundary problem. Establish
   whether it is nonzero on the chosen interaction interval. The existence
   theorem and a reference contact time do not establish this by themselves.
4. Evaluate the second variation using the exact initial family's weighted
   second correction and the full quadratic shell/bulk sources. Track which
   response coefficients depend on the nonlinear initial completion.
5. If numerical evolution is used, record constraint, gauge and boundary
   residuals, resolution convergence and truncation error. Compare its
   first two amplitude derivatives with the analytic variation equations.
   An unvalidated time trace is not a nonvanishing proof.

A useful quadratic diagnostic is the squared first scalar response integrated
against the background induced spatial measure on a specified shell section.
Its positivity is equivalent to nonvanishing of that scalar response on the
section. The relation to an exactly defined finite-amplitude observable and
its slicing dependence should be derived explicitly in the next checkpoint.
This is a response diagnostic, not gravitational energy or a cosmological
prediction.

A successful next checkpoint would contain an explicit, reproducible response
for at least one registered profile, an honest nonvanishing/error statement,
and an account of gauge and initial-completion dependence. Comparison with
cosmological data requires additional physical modeling and is not inferred
from the conditional existence result. No Zenodo version or APS submission
is requested by this planning note.
