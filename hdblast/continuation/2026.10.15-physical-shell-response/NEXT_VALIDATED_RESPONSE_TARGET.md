# Next target: a validated waveform and physical response magnitude

The present checkpoint proves conditional qualitative nonvanishing for one
explicitly registered aligned profile. It gives the complete linear
characteristic/Volterra transfer and a positive exact-family quadratic
response coefficient, but no numerical value.

1. Select one actual background member within the registered branch and
   carry verified background and shell-parameter errors into its coefficients.
   Historical coefficients from a different scalar branch are not substitutes.
2. Solve the complete coupled linear transfer for the specified normalized
   bump, including the positive-inertia shell ODE and the wave it returns to
   the bulk. Retain the ambient/global velocity conversion and exact shell law.
3. Bound the observation-norm error using the Volterra/energy estimates,
   boundary and initial residuals, coefficient errors and domain truncation.
   Resolution convergence alone is not an error certificate.
4. Compute an interval for the proper-time-window coefficient C_T1 and show
   its lower endpoint is positive. This would supplement the qualitative
   activation proof with a numerical magnitude.
5. Obtain an effective parameter-remainder bound if a numerical amplitude
   interval for the exact nonlinear response is desired. Track dependence on
   the nonlinear initial completion beyond the leading quadratic coefficient.

The proper-time clock is relative to the marked initial physical shell cut.
The linear arrival infimum does not determine the exact nonlinear first
arrival: exact constraint corrections can occupy a larger annulus and launch
smaller-order signals earlier. A response functional is not gravitational
energy or a cosmological prediction. Comparison with observations requires
additional physical modeling. No Zenodo version or APS submission is requested
by this planning note.
