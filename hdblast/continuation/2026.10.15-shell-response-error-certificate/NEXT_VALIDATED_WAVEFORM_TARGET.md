# Next target: a useful-scale waveform with a sharp error certificate

The present result encloses the leading coefficient for the newly specified delta=1/1000, ell=10^-10 model state. Its analytic comparator deliberately trades accuracy for a simple strict bound. The next calculation should resolve the actual physical shell waveform at a separately registered profile width and carry an explicit observation-norm certificate.

1. Choose the width, time window and correction annulus before running numerics; retain the whole nonlinear support margin and the actual fixed background branch. Do not extrapolate the tiny-width interval to another state.
2. Enclose background coefficients over the required collar using exact analytic bounds and validated ODE propagation. The existing floating trajectories can guide approximation but are not validated coefficient inputs.
3. Solve the characteristic bulk equations together with the positive-inertia shell ODE and the wave reflected back into the bulk. Approximate both the solution and its continuous reconstruction.
4. Certify bulk, boundary, initial and coefficient residuals. Apply the derivative-trace estimator to the physical output w_z-(C_b/2)w, and compare its certified norm with the trial norm. Include interval errors in rho_b, p_b, mu, beta and C_b.
5. Report a waveform enclosure and a leading-coefficient interval, with model units and data normalization explicit. Refinement convergence alone is not a certificate.
6. Obtain an effective nonlinear remainder bound before claiming any finite epsilon response magnitude. The leading coefficient alone gives no effective amplitude range, observational scale or cosmological-origin inference.

An additional useful consistency target is short-width scaling, derived from the same comparator rather than assumed from a numerical fit. It would concern a family of differently normalized high-gradient states and require explicit uniform constants; no such new scaling theorem is asserted by this planning note.
